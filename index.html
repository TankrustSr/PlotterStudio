Hardware Wiring, GRBL Settings & Stepless G-Code Setup

                    
    
                        
  • Controller PWM Output (D11 / TTL / Laser PWM)  Arduino Nano Pin D2 (Hardware Interrupt 0) + Common GND.
    • 
                        
  • Servo Signal Wire  Arduino Nano Pin D9 (Use external 5V BEC for servo power to prevent brownouts).
    • 
                        
  • Pen-Up Pulse (1100 μs): Automatically triggered whenever GRBL sends S0 or G0 rapid travel.
    • 
                        
  • Recommended GRBL Settings: Set $30=1000 (Max Spindle/PWM ceiling), $31=0 (Min Spindle), and use M3 Constant Power Mode so corner deceleration never lifts your brush pen.
    • 
                        
  • Continuous Stepless G-Code (G1 X... Y... S...): Every vertex outputs an exact S value from S100 to S1000, updating your Nano's servo angle smoothly 50+ times per second without pausing XY motion!
